# Máquina de Estados em C - Caixa Eletrônico

## Execução

```bash
make test
```

Requer GCC e Make. Os testes usam `assert` e falham com código de saída diferente de zero se houver violação.

## Arquivos
- `atm.h`: tipos e interface.
- `atm.c`: implementação.
- `testes.c`: testes automatizados.
- `Makefile`: compilação e execução.

## Publicação
Crie um repositório Git, adicione estes arquivos e substitua o campo de URL pendente no relatório pelo endereço real do repositório.
